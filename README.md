# 💡 Got an Idea? Let's Build It

> **Idea → Design → Build → Ship**

I enjoy taking a rough idea and turning it into something people can actually use. If you have a product, a feature, or a problem to solve, this is how I like to work:

| Step | What happens |
| --- | --- |
| 💭 **Understand** | Clarify the problem, the users, and what "done" looks like |
| 🎨 **Design** | Sketch the data model, API, and UI before writing code |
| ⚙️ **Build** | Develop in small, tested steps with clean, reusable code |
| 🚀 **Ship** | Deploy, measure, and keep improving |

### 🤖 Coding with Cursor & Claude
